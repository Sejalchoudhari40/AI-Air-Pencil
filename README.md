\# ✋ AI Air Pencil



AI Air Pencil is a real-time computer vision project that allows users to draw in the air using hand gestures through a webcam.



Instead of using a physical mouse or touchscreen, the system tracks the user's hand and uses the index finger as a virtual pencil.



\## ✨ Features



\- 🎥 Real-time hand tracking using MediaPipe

\- ☝️ Index finger based drawing

\- 🤖 Hand gesture recognition

\- 🎨 Multiple drawing colors

\- 🖌️ Virtual eraser

\- 📐 Coordinate smoothing

\- ✋ Gesture stabilization

\- 🚫 Sudden movement rejection

\- 🖼️ Binary drawing mask

\- 🧹 Canvas clearing

\- ⚡ Real-time interaction



\## 🖐️ Gestures



| Gesture | Action |

|---|---|

| ☝️ Index Finger | Draw |

| ✌️ Two Fingers | Select Color |

| 🖐️ Open Palm | Erase |

| ✊ Fist | Idle |
